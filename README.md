# RTG LoRa Fuel Telemetry System

An industrial IoT solution designed to monitor the fuel level of Rubber-Tyred Gantry (RTG) cranes using ESP32, SX1262 LoRa, and an A7670G LTE gateway.

The system eliminates manual fuel inspections by wirelessly transmitting fuel level data from RTG crane nodes to a central gateway over LoRa. The gateway uploads the data to the Blynk Cloud for real-time remote monitoring and simultaneously sends SMS notifications to designated personnel through the A7670G LTE modem, enabling timely monitoring and alerts even when the Blynk application is not actively in use.
